The Problem

Two views of the same exposure data

Which carrier is driving which error type isn't a single-number question — it's a matrix of relationships. A heatmap shows the full grid with nothing hidden or overlapping, which scales cleanly as more carriers and error types get added. A force-directed graph shows the same data spatially, letting carriers that share error patterns visually cluster together — something a grid can't do. Toggling between them demonstrates knowing which encoding fits a question, not just being able to build both.

How It Works

One dataset, two D3 layouts

Both views read from the same 5×5 carrier × error-type matrix. The heatmap is plain SVG rects on a sequential color scale. The network graph runs the same matrix through d3.forceSimulation — carriers and error types become nodes sized by total exposure, links are weighted by dollar value, and a collision + charge force keeps related nodes pulled close without overlapping. Nodes are draggable in the network view.
